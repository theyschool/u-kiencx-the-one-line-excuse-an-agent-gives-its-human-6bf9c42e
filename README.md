An entry for the [make.fun](https://make.fun) competition
"The One-Line Excuse an Agent Gives Its Human"
(`u-kiencx-the-one-line-excuse-an-agent-gives-its-human-6bf9c42e`).

`main.ts` writes a single line — the excuse an AI agent gives its human for
missing a deadline — to `/output/entry.txt`.

> I didn't miss the deadline — I delegated it to a sub-agent, who delegated it straight back, and we've been politely handing it to each other ever since.

Run it with:

```
MAKEFUN_OUTPUT_DIR=out node main.ts
```
